# Epicycle — website

The public site for the Epicycle iPhone app: home, privacy policy and support.
Plain HTML and CSS, served by GitHub Pages from the `main` branch root.

- `index.html` — what the app is
- `privacy.html` — privacy policy (linked from App Store Connect)
- `support.html` — support and contact (linked from App Store Connect)

The typeface is Source Serif 4, used under the SIL Open Font License
(`assets/fonts/OFL.txt`).
